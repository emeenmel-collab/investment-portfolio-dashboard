# Investment Portfolio Dashboard

An interactive, browser-based investment portfolio tracker built with HTML, CSS, and JavaScript. This project demonstrates foundational financial analysis, portfolio visualization, and front-end development.

## Project Overview

The dashboard allows users to explore a sample investment portfolio, review its holdings, and analyze portfolio allocation and unrealized gains or losses.

## Features

- **Portfolio summary:** View portfolio market value, cost basis, total unrealized gain or loss, and percentage return.
- **Holdings management:** Add and remove investments and edit share quantities and prices.
- **Asset allocation:** Visualize how portfolio value is distributed across holdings.
- **Portfolio analytics:** Identify the largest holding, its portfolio weight, and the number of profitable positions.
- **Performance visualization:** Explore an illustrative portfolio value chart with selectable time ranges.
- **CSV export:** Export portfolio holdings for further analysis in a spreadsheet.
- **Responsive interface:** Use the dashboard on desktop and smaller screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart visualization using CSS and JavaScript
- CSV export using browser functionality

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Add or edit sample holdings and explore the dashboard features.

No build tools or package installation are required for the current version.

## Sample Data and Limitations

The portfolio uses illustrative sample holdings and prices. It does not currently connect to a brokerage account or retrieve live market prices.

The performance chart is illustrative and should not be interpreted as actual historical portfolio performance. Results are based on the holdings and prices entered into the dashboard.

This project is for educational and portfolio-demonstration purposes only and is not investment advice.
